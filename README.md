## About This Repository

This repository contains the practical implementations of the **Design and Analysis of Algorithms (DAA)** laboratory.

It includes different algorithm design techniques, problem-solving approaches, and practical implementations using Python. Each unit is organized into separate folders containing source code, documentation, and output screenshots.

## Units and Experiments

| Unit | Topic |

| 02 | Divide and Conquer |
| 03 | Greedy Method |

| 05 | Traversal and Search |
| 06 | Backtracking |
| 07 | NP-Hard and NP-Complete |

## How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run an experiment using Python:

```bash
python path/to/main.py
```
