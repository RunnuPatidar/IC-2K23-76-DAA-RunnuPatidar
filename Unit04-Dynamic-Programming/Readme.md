# Unit 4: Dynamic Programming

## Overview
Dynamic Programming is an algorithm design technique that solves complex problems by dividing them into smaller overlapping subproblems and storing their results to avoid repeated calculations.

## Experiments

1. **Recursive Fibonacci:** Generates Fibonacci numbers using recursion.
2. **Memoized Fibonacci:** Uses memoization to reduce repeated calculations.
3. **0/1 Knapsack:** Finds the maximum value of selected items within a given capacity.
4. **Multistage Graph:** Finds the minimum-cost path in a multistage graph.
5. **Floyd-Warshall:** Finds shortest paths between all pairs of vertices.
6. **Single-Source Shortest Path:** Implements Bellman-Ford to find shortest distances from a source vertex.
7. **Traveling Salesperson Problem:** Finds an optimal tour using Bitmask Dynamic Programming.
