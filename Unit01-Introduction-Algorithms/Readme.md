# Unit 1: Introduction to Algorithms

## Overview
This unit introduces the basic concepts of algorithms, their implementation, and performance analysis using Python. Different searching and array operations are implemented to understand how algorithms work and how their efficiency can be measured.

## Experiments

### 1. Array Operations
Implemented basic array operations such as insertion, deletion, searching, and displaying elements.

### 2. Iterative Binary Search
Implemented binary search using an iterative approach to find an element in a sorted array.

### 3. Recursive Binary Search
Implemented binary search using recursion and studied its time and space complexity.

### 4. Complexity Analysis
Analyzed the best, average, and worst cases of linear search by counting the number of comparisons.

### 5. Performance Measurement
Measured the execution time of linear search for different input sizes and represented the results using a graph.

### 6. Algorithm Performance Analyzer
Developed a simple performance analyzer to compare experimental execution time with theoretical time complexity.

## Technologies Used
- Python
- Matplotlib
- CSV
- VS Code

## Learning Outcomes
- Understood the basic concept of algorithms.
- Learned how to perform array operations.
- Implemented iterative and recursive binary search.
- Understood best-case, average-case, and worst-case complexity.
- Learned to measure execution time for different input sizes.
- Visualized algorithm performance using graphs.

## Conclusion
This unit provided practical knowledge of algorithm implementation and analysis. It helped in understanding the relationship between input size, execution time, and algorithm efficiency.
