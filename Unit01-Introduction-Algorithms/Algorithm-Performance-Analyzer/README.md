
# Experiment 6: Algorithm Performance Analyzer

## Aim
To develop an analyzer that compares theoretical
and experimental algorithm performance.

## Problem Statement
Measure the execution time of Linear Search
for different input sizes and compare it
with theoretical O(n) complexity.

## Algorithm
1. Define Linear Search.
2. Generate input arrays of different sizes.
3. Measure execution time.
4. Store the results in CSV format.
5. Generate a comparison graph.
6. Display theoretical complexity.

## Pseudocode
START
FOR each input size n
    Generate array of size n
    Measure Linear Search execution time
    Store input size and execution time
END FOR
Save results
Generate graph
Display complexity analysis
STOP

## Complexity Analysis

Time Complexity: O(n)
Space Complexity: O(n) including input array.

## Experimental Results
The analyzer records execution times
for different input sizes.

## Performance Analysis
The theoretical reference is O(n).
The measured execution time may vary
depending on hardware and system load.

## Learning Outcomes
- Developed a performance analyzer.
- Learned theoretical complexity comparison.
- Measured execution time.
- Generated experimental graphs.
