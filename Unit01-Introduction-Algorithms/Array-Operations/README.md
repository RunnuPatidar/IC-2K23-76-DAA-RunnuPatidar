
# Experiment 1: Basic Array Operations

## 1. Aim
To implement basic operations such as insertion,
deletion, searching and traversal on an array.

## 2. Problem Statement
Write a Python program to perform basic operations
on an array using a menu-driven approach.

## 3. Algorithm
1. Initialize an array.
2. Display a menu of operations.
3. Accept the user's choice.
4. Perform insertion, deletion, searching or display.
5. Validate the entered position.
6. Repeat until the user exits.

## 4. Pseudocode
START
Initialize array
REPEAT
    Display menu
    Read choice
    IF choice = 1
        Display array
    ELSE IF choice = 2
        Insert element
    ELSE IF choice = 3
        Delete element
    ELSE IF choice = 4
        Search element
    ELSE
        Exit
UNTIL user exits
STOP

## 5. Complexity Analysis

| Operation | Time Complexity |
|---|---|
| Traversal | O(n) |
| Insertion | O(n) |
| Deletion | O(n) |
| Searching | O(n) |

Space Complexity: O(n)

## 6. Sample Input / Output
Initial Array: [10, 20, 30, 40, 50]

After insertion:
[10, 20, 60, 30, 40, 50]

## 7. Experimental Results
The program successfully performs insertion,
deletion, searching and traversal operations.

## 8. Learning Outcomes
- Understood array operations.
- Learned insertion and deletion.
- Implemented linear searching.
- Understood time complexity.
