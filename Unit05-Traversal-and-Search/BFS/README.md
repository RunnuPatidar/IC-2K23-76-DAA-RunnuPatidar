# Breadth First Search (BFS)

## Aim
To implement Breadth First Search for graph traversal.

## Theory
BFS is a graph traversal algorithm that visits vertices level by level.
It uses a queue data structure.

## Algorithm
1. Initialize an empty queue.
2. Mark the starting vertex as visited.
3. Insert the starting vertex into the queue.
4. Remove a vertex from the queue and display it.
5. Visit all its unvisited adjacent vertices.
6. Insert them into the queue.
7. Repeat until the queue becomes empty.

## Time Complexity
O(V + E)

## Space Complexity
O(V)

## Sample Output
BFS Traversal: A B C D E F

## Learning Outcome
Learned graph traversal using the Breadth First Search algorithm.
