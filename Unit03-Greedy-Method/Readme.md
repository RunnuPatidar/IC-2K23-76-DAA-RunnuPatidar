# Unit 3: Greedy Method

## Overview
The Greedy Method is an algorithm design technique that makes the best available choice at each step to solve an optimization problem. This unit focuses on implementing Greedy algorithms and understanding their applications.

## Experiments

### 1. Fractional Knapsack
Selects items according to their value-to-weight ratio to maximize the total value within a given capacity.

### 2. Job Sequencing with Deadlines
Schedules jobs before their deadlines to maximize total profit.

### 3. Prim's Algorithm
Finds a Minimum Spanning Tree by repeatedly selecting the minimum-weight edge connecting the current tree to an unvisited vertex.

### 4. Kruskal's Algorithm
Finds a Minimum Spanning Tree by selecting edges in increasing order of weight while avoiding cycles.

### 5. Minimum-Cost Network Design
Applies Prim's and Kruskal's algorithms to design a minimum-cost network and compare their results.
